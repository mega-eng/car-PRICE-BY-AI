# CarInsight AI — تقدير سعر السيارة من الصورة

مودل يقدّر سعر السيارة من صورها فقط (بدون ماركة أو سنة أو ممشى)، ويعطي نطاقاً محتملاً 80% و90%.

**نتائج الاختبار (345 إعلان لم يرها المودل):** الخطأ النسبي الوسيط 10.7%، R² = 0.848، متوسط الخطأ 15,908 ر.س.

## محتويات المستودع
| المسار | الوصف |
|---|---|
| `docs/` | لوحة النتائج التفاعلية (GitHub Pages) |
| `app/` | تطبيق لتجربة المودل محلياً (Gradio) مع المودل المدرّب `bundle.joblib` |
| `src/image_to_price_v2.py` | كود التدريب والتقييم |
| `notebooks/` | دفتر Colab لإعادة التدريب |

## تجربة التطبيق مباشرة
[افتح CarInsight AI على Gradio](https://a44cf3ff34de81772a.gradio.live/)

## الموقع والنشر

- واجهة GitHub Pages الثابتة موجودة في مجلد المستودع الجذري `docs/`، وليست هذا المجلد المتداخل.
- صفحة تقدير السعر: `https://mega-eng.github.io/car-PRICE-BY-AI/predict.html` بعد تفعيل Pages من `Settings → Pages` واختيار الفرع `main` والمجلد `/docs`.
- الخلفية موجودة في [`api/`](./api/README.md). يجب نشرها منفصلًا ثم ضبط `docs/api-config.js` برابط API.

## عرض اللوحة
Settings ← Pages ← Branch `main` ← Folder `/docs`. تظهر على `https://USERNAME.github.io/REPO/`

## تجربة المودل على جهازك
```bash
pip install -r app/requirements.txt
cd app && python app.py
```
يفتح رابطاً محلياً في المتصفح، ارفع صور سيارة ويطلع السعر المقدّر مع النطاق. أول تشغيل ينزّل الشبكات من الإنترنت فياخذ وقتاً.

## إعادة التدريب
افتح الدفتر في `notebooks/` على Google Colab (GPU) وشغّل الخلايا بالترتيب. يحتاج ملف صور (zip) وملف بيانات (csv) بنفس أعمدة الداتا الأصلية.

> الداتا والصور الكاملة غير مرفوعة عمداً (`.gitignore`).
